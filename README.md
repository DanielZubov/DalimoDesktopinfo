# 🖥️ DalimoDesktopInfo

Легковесный и настраиваемый виджет для рабочего стола Windows, предназначенный для отображения ключевой системной информации. Идеально подходит для развертывания в домене через групповые политики (GPO).

## ✨ Возможности

*   **Мониторинг в реальном времени:** Отображает имя ПК, пользователя, аптайм и сетевые адаптеры (IP, MAC).
*   **Гибкая настройка:** Контекстное меню позволяет менять цвета, размеры шрифтов для каждого элемента отдельно, а также настраивать прозрачность и цвет фона.
*   **Авто-восстановление:** Виджет автоматически возвращается в правый верхний угол каждую минуту, если пользователь его случайно переместил.
*   **Работа в трее:** Управление приложением доступно через иконку в системном лотке. Двойной тап по иконке включает отображение программы если она была скрыта.
*   **Портативность:** Не требует установки .NET (использует встроенный в Windows .NET Framework 4.8).

## 🚀 Установка и развертывание

1.  Скачайте последний релиз из раздела [Releases](https://github.com/DanielZubov/DalimoDesktopinfo/releases).
2.  Скопируйте исполняемый файл в папку (например, `C:\Program Files\DalimoDesktopInfo`).
3.  Запустите `DalimoDesktopinfo_*.exe`.

**Развертывание через GPO:**
Приложение не требует прав администратора. Вы можете распространить папку с программой через сценарии запуска компьютера (Computer Startup Scripts) в групповых политиках.

## 🛠️ Сборка из исходного кода

Для сборки проекта вам потребуется:
*   Visual Studio 2022 (или новее) с установленным компонентом **«Разработка классических приложений .NET»**.
*   Целевая платформа: **.NET Framework 4.8**.

1.  Клонируйте репозиторий.
2.  Откройте файл решения `.sln` в Visual Studio.
3.  Нажмите `F5` для отладки или «Сборка» -> «Опубликовать» для создания релизной версии.
